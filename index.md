# Gmail Attachment Downloader

## Personal Gmail Attachment Backup

Gmail Attachment Downloader is a personal desktop application designed to download and organize email attachments from a Gmail account.

### Features

- Downloads Gmail attachments using Google's Gmail API.
- Organizes attachments into folders by year.
- Avoids downloading previously processed attachments.
- Handles temporary API rate limits.
- Supports scheduled backups on Windows.

### Privacy and Security

The application requests read-only access to Gmail. It does not modify, send, or delete emails.

Downloaded attachments are stored locally on the user's computer.

The application is intended for personal use and is not offered as a public service.

For more information, see the [Privacy Policy](privacy.md).
