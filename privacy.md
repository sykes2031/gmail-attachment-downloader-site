# Privacy Policy

**Application:** Gmail Attachment Downloader  
**Last updated:** November 7, 2026

## 1. Purpose

Gmail Attachment Downloader is a personal-use desktop application that downloads and organizes attachments from a Gmail account.

## 2. Google Account Access

The application uses Google's Gmail API with the `gmail.readonly` permission.

This permission allows the application to read Gmail messages and download attachments. The application does not send, modify, or delete emails.

## 3. Data Collection and Storage

The application processes Gmail messages and attachments to create local backups.

Downloaded attachments are stored on the user's Windows computer and organized by year.

Authentication credentials and download-history information are stored locally.

## 4. Data Sharing

The application does not intentionally transmit Gmail message contents or attachments to third-party services. Gmail API requests are processed through Google's services.

The application does not sell Gmail data or use it for advertising.

## 5. Data Retention and Deletion

Downloaded attachments remain on the user's computer until the user deletes them.

The user can remove locally stored attachments and revoke the application's Google Account access.

## 6. Security

The application uses Google's OAuth 2.0 authentication system.

The application does not request the user's Gmail password.

## 7. Google API Services User Data Policy

The application's use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including applicable Limited Use requirements.

## 8. Changes

This policy may be updated if the application's functionality or data-handling practices change.
